# GASA demo site

Static pitch site for the GASA Scam Fighter Awards 2026 (Tunic Pay).
Fully self-contained HTML — no backend, no CDN, works offline once loaded.

- `index.html` — landing (Slides / Live demo)
- `slides.html` — the 4-minute animated deck
- `demo.html` — the interactive two-pane demo

Served via GitHub Pages (Settings → Pages → Deploy from branch → main / root).
